## Key Finding
Despite Hamilton braking later than Verstappen at most corners,
Verstappen was 0.6 seconds faster overall.
Analysis of throttle traces shows Verstappen applied full throttle
earlier after every corner — indicating superior traction from
the Red Bull RB19 compared to the Mercedes W14.
